  1. Verificar el estado del repositorio: Comprueba qué archivos han sido modificados o están pendientes con git status.
  2. Añadir los archivos al área de preparación (staging): Prepara los cambios que deseas guardar utilizando git add < archivo > o git add . para incluir todos los archivos.
  3. Realizar el commit local: Guarda una instantánea de los cambios en tu repositorio local con un mensaje descriptivo usando git commit -m "Mensaje del commit".
  4. Enviar los cambios al repositorio remoto: Sube los commits acumulados a la rama del servidor remoto mediante git push origin < nombre-de-la-rama > (por ejemplo, git push origin main)
  • HTML

  • HTML son las siglas en inglés de HyperText Markup Language (Lenguaje de Marcado de Hipertexto). Es el lenguaje estándar que se utiliza para crear y estructurar el contenido de las páginas web
  • CSS (siglas en inglés de Cascading Style Sheets, o Hojas de Estilo en Cascada) es un lenguaje de diseño gráfico que se utiliza para definir la apariencia, el color, la tipografía, el espaciado y la maquetación de los documentos escritos en HTML o XML.
  • El DOM (Document Object Model o Modelo de Objetos del Documento) es una interfaz de programación que representa los documentos HTML o XML como una estructura de árbol jerárquico en la memoria del navegador.
